## P9-B1.1 Addendum — Four Cooling Parameters

Extend the required extraction and effective-value resolution scope from four to eight parameters.

In addition to the existing four priority parameters, include:

1. Minimum fan speed.
2. Maximum fan speed.
3. Layer-time threshold associated with minimum fan speed.
4. Layer-time threshold associated with maximum fan speed.

Before implementing the mapping:

- Inspect Bambu Studio source code and real exported Filament Preset JSON files.
- Identify the exact JSON keys and 3MF project configuration keys for all four parameters.
- Verify the relationship between fan-speed endpoints and their corresponding layer-time thresholds.
- Determine whether each field is filament-specific, configuration-indexed, inherited, or overridden.
- Verify the array indexing rules independently for each parameter.
- Preserve the original values, units, source paths, and resolution evidence.
- Do not assume that the two layer-time thresholds share the same indexing or storage semantics.
- Do not infer missing values from defaults without a verified inheritance chain.

Add extraction and resolution tests for all four cooling parameters, including the real H2D fixture where applicable.

P9-B2 must compare these eight parameters only when both values are reliably resolved. Missing or ambiguous values must produce explicit unresolved results rather than false mismatches.

Update the parameter mapping, fixture matrix, resolution rules, and implementation report accordingly.
